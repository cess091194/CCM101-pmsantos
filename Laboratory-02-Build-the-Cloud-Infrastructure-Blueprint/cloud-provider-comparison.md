# Cloud Provider Comparison Table
| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 (Simple Storage Service) | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC (Virtual Private Cloud) | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

**1. Which cloud provider offers the broadest range of services? Explain your answer.**

AWS offers the broadest range of services among the three providers. 
Being the first major public cloud platform (launched in 2006), it has 
had the most time to build out specialized services across compute, 
storage, databases, machine learning, IoT, and more. As of now, AWS 
lists hundreds of distinct services, giving customers highly granular 
options for almost any workload.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**

Microsoft Azure would be the best fit for an organization built around 
Microsoft products. Azure integrates natively with Microsoft 365, 
Windows Server, .NET, and Microsoft Entra ID for identity management, 
which reduces licensing costs and administrative complexity compared to 
running a Microsoft-heavy environment on a non-Microsoft cloud.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**

Google Cloud Platform is widely recognized in this area. Kubernetes 
was originally developed by Google, and GCP's Google Kubernetes Engine 
(GKE) is considered the industry reference implementation. GCP is also 
known for its AI/ML tools such as Vertex AI and TensorFlow, which was 
also developed by Google.

**4. What similarities did you observe among the three cloud providers?**

All three providers offer the same core categories of infrastructure: 
scalable compute (virtual machines), object/blob storage, virtual 
networking to isolate and connect resources, and an IAM service to 
control access. All three also use a pay-as-you-go pricing model, 
operate data centers across multiple global regions, and provide 
managed Kubernetes services for container orchestration.
