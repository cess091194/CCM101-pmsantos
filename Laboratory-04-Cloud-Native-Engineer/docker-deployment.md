# Docker Deployment Log

## Container Lifecycle Commands

1. **`docker ps`** — Lists all currently running containers.
2. **`docker stop my-nginx`** — Gracefully stops the running Nginx container.
3. **`docker ps -a`** — Lists all containers (running and stopped) to verify the container's status.
4. **`docker rm my-nginx`** — Permanently removes the stopped container from the system.
