# Docker Deployment Log

## Container Lifecycle Commands

1. `docker ps` — shows the containers that are currently running.
2. `docker stop my-nginx` — stops the running Nginx container.
3. `docker ps -a` — shows all containers, running or stopped, to confirm it was stopped.
4. `docker rm my-nginx` — deletes the stopped container from the system.
