# Microsoft Azure

## Brief Overview
Microsoft Azure is Microsoft's public cloud platform, launched in 2010. Azure is especially strong for organizations already invested in Microsoft products (Windows Server, Active Directory, Microsoft 365, .NET), and it is typically the second-largest cloud provider by market share after AWS.

## Global Infrastructure
Azure infrastructure is built around **Regions**, grouped into **Geographies** (which help meet data residency and compliance requirements), and many Regions contain **Availability Zones** for fault tolerance. Azure also has **Region Pairs** — two Regions in the same geography used for disaster recovery — and a global network of **Edge/PoP locations** for its CDN.

## Cloud Management Console
The **Azure Portal** is the web-based console for managing Azure resources. Azure also provides **Azure CLI**, **Azure PowerShell**, and **Azure Cloud Shell** (a browser-based shell), plus **Azure Resource Manager (ARM)** for infrastructure-as-code deployments.

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand, scalable virtual servers.
2. **Azure Blob Storage** – Object storage for unstructured data such as documents, images, and backups.
3. **Azure SQL Database** – Managed relational database service built on SQL Server.
4. **Azure Virtual Network (VNet)** – Lets you provision an isolated, private network within Azure to control how your resources connect and communicate.

## Three (3) Advantages
1. **Best Microsoft integration** – Seamless connection with Windows Server, Active Directory, Microsoft 365, and .NET applications.
2. **Strong hybrid cloud support** – Azure Arc and Azure Stack make it easy to extend on-premises environments into the cloud.
3. **Enterprise trust and compliance** – Wide range of certifications, favored by large enterprises and government agencies already using Microsoft tools.

## Typical Enterprise Use Cases
1. **Organizations migrating from on-prem Windows Server/Active Directory** to a hybrid or full-cloud environment.
2. **Enterprises standardized on Microsoft 365** wanting unified identity and security management via Entra ID.
3. **Line-of-business .NET applications** being modernized or moved to Azure App Service.
