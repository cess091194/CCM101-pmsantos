# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform is Google's public cloud offering, built on the same infrastructure that powers Google Search, YouTube, and Gmail. GCP is generally considered the strongest platform for **data analytics, machine learning, and Kubernetes/container orchestration**, since Google originally created Kubernetes.

## Global Infrastructure
GCP infrastructure is organized into **Regions** and **Zones** (similar to AWS Availability Zones). GCP is also known for its private global fiber network, which connects its data centers directly rather than relying heavily on the public internet, contributing to lower latency between GCP services worldwide.

## Cloud Management Console
The **Google Cloud Console** is the web-based dashboard for managing GCP resources. GCP also provides the **gcloud CLI**, client SDKs, and **Cloud Shell**, a free browser-based terminal with the gcloud CLI pre-installed.

## Four (4) Core Services
1. **Compute Engine** – Customizable virtual machines for general-purpose workloads.
2. **Cloud Storage** – Object storage for unstructured data, similar to S3/Blob Storage.
3. **Cloud SQL** – Managed relational database service (MySQL, PostgreSQL, SQL Server).
4. **Google Kubernetes Engine (GKE)** – Managed Kubernetes service for deploying and scaling containerized applications.

## Three (3) Advantages
1. **Strongest AI/ML tooling** – Vertex AI, TensorFlow origins, and TPUs (Tensor Processing Units) give GCP an edge for AI/ML workloads.
2. **Best-in-class Kubernetes support** – As the creator of Kubernetes, GCP's GKE is widely seen as the most mature managed Kubernetes offering.
3. **Strong data analytics tools** – BigQuery offers fast, serverless, large-scale data warehousing and analytics.

## Typical Enterprise Use Cases
1. **AI/ML research and product teams** training and deploying models using Vertex AI and TPUs.
2. **Data-heavy companies** running large-scale analytics and reporting through BigQuery.
3. **Cloud-native companies** running containerized microservices architectures on GKE.
