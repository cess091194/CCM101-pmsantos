# Reflection

Completing this mission as part of the Cloud Evaluation Team gave me a much deeper understanding of how the three major cloud platforms compare in real-world scenarios. Of the three, Google Cloud Platform impressed me the most, mainly because of how strong it is in AI/Machine Learning and Kubernetes. Knowing that Google created Kubernetes and built tools like Vertex AI and TPUs specifically for machine learning made me realize how each provider has developed its own specialty, rather than just being generic "cloud" options competing on the same features.

At the same time, researching all three platforms showed me how much they actually have in common. AWS, Azure, and GCP all share the same core building blocks: virtual machines for compute, object storage for files, managed relational databases, virtual networking, and identity and access management tools. They also all offer a web-based console, a command-line interface, free-tier options, and global infrastructure built on regions and zones for redundancy. The real differences show up in pricing, specialization, and ecosystem integration rather than the basic services themselves.

This mission also made it clear that there's no single "best" cloud provider — the right choice always depends on the client's specific needs. A startup cares about low cost and fast scaling, a university already using Microsoft tools benefits most from Azure's integration, and an AI research company needs GCP's specialized ML hardware. Business requirements, not personal preference, should drive the recommendation.

Acting as a Cloud Solutions Consultant taught me to think beyond just "which platform is more popular" and instead evaluate services, pricing, and integration in the context of a client's actual problem, while also learning how to justify a technical recommendation clearly enough for a non-technical audience to understand.

Finally, my GitHub Cloud Computing Portfolio is now more organized and professional, with structured Markdown documentation, comparison tables, and real terminal screenshots as evidence. It now reflects not just theoretical knowledge, but practical, hands-on experience researching and comparing real cloud platforms.
