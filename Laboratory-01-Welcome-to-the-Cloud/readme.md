# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This laboratory activity simulates the onboarding
process of a Junior Cloud Infrastructure Engineer
Trainee at CloudNova Technologies. It involves setting
up a cloud-based Linux environment using KillerCoda,
exploring the system, organizing files, and
documenting the process through a GitHub repository.

## Objectives
- Access a cloud-based Linux environment using
  KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub
  repository
- Document technical work using Markdown

## Activities Performed
1. Launched an Ubuntu 24.04 playground via KillerCoda
2. Created a new user account (pmsantos) with sudo
   access and logged in
3. Investigated system information (distribution,
   kernel, CPU, memory, disk space)
4. Created folder structure (Documents, Notes,
   Reports, Screenshots) and an about-me.md file
5. Created a public GitHub repository and organized
   it according to the required structure
6. Documented the mission and captured evidence
   through screenshots
7. Committed and pushed all work to GitHub

## Linux Commands Used
- `sudo adduser`, `usermod -aG sudo`, `su`
- `whoami`, `pwd`, `hostname`
- `cat /etc/os-release`, `uname -r`, `lscpu`,
  `free -h`, `df -h`
- `mkdir`, `touch`, `nano`, `ls`, `cat`
- `git clone`, `git add`, `git commit`, `git push`

## Skills Learned
- Managing Linux users and permissions
- Navigating and inspecting system information
- Organizing files and directories professionally
- Writing documentation using Markdown
- Using Git and GitHub for version control and
  portfolio building
