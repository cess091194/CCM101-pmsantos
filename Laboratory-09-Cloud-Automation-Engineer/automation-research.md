# Automation Research

## Bash Script
A Bash script is a plain text file that holds a list of Linux commands, so the computer can run them one after another without someone typing each one. It is like a recipe the server follows every time. The first line, `#!/bin/bash`, is called the shebang, and it tells the system to use Bash to run the file.

## Variables
Variables are names that store a value, like a folder path, so it can be reused anywhere in a script. Programmers use them instead of typing the exact path every time because the path only has to be changed in one place if it ever changes. This also means fewer typos and a script that is easier to read and update.

## Cron Job
A cron job is a task that Linux runs automatically at a set time, like every night at 2:00 AM. It is essential for cloud operations because routine jobs such as backups and cleanups happen on schedule without a person having to remember them. This keeps servers consistent and saves a lot of manual work, especially when there are many servers.
